# Project 13 – AI Recommendation System

## Objective

Recommend products based on a user's preferred category.

---

## Topics Covered

- Product Recommendation
- Data Filtering
- Data Sorting
- Report Generation

---

## Install

```bash
pip install -r requirements.txt
```

---

## Run

```bash
python src/recommendation_system.py
```

---

## Output

```text
outputs/
├── recommended_products.csv
└── recommendation_report.txt
```

---

## Conclusion

This project demonstrates a simple recommendation system by filtering products according to a selected category and displaying the highest-rated products.
