# Project 10 – End-to-End Machine Learning Workflow

## Objective

Demonstrate a complete machine learning workflow from reading a dataset to generating predictions.

---

## Topics Covered

- Data Loading
- Feature Selection
- Train-Test Split
- Decision Tree Classification
- Prediction
- Saving Results

---

## Install

```bash
pip install -r requirements.txt
```

---

## Run

```bash
python src/ml_workflow.py
```

---

## Output

```text
outputs/
├── predictions.csv
└── workflow_report.txt
```

---

## Conclusion

This project demonstrates the complete workflow of a simple machine learning application, including data preparation, model training, prediction, and report generation.
