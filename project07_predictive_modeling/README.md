# Project 07 - Predictive Modeling

## Objective

To build a supervised machine learning model that predicts whether a customer will purchase a product.

## Machine Learning Type

Supervised Learning

## Algorithm Used

Logistic Regression

## Dataset

Customer information is used:

- Age
- Income
- Website visits
- Previous purchases

Target:

- Purchase (Yes/No)

## Workflow

1. Load dataset
2. Separate input and output columns
3. Split data into training and testing sets
4. Train machine learning model
5. Test model performance
6. Generate accuracy report

## Output

The project creates a model_report.txt file containing:

- Problem description
- Algorithm details
- Accuracy
- Performance result
- Conclusion

## Tools Used

- Python
- Pandas
- Scikit-learn
