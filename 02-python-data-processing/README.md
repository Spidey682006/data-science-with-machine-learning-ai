# Project 02 – Python Data Processing

## Objective

The objective of this project is to process employee data using core Python programming concepts. The application reads employee records from a CSV file, performs basic data analysis, and generates a summary report.

---

## Concepts Used

- Variables
- Data Types
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- File Handling
- CSV Processing
- Exception Handling

---

## Dataset

The project uses a simple employee dataset containing:

- Employee ID
- Name
- Department
- Salary
- Years of Experience

---

## Features

- Read employee records from a CSV file.
- Count the total number of employees.
- Calculate the average salary.
- Identify the employee with the highest salary.
- Filter employees with five or more years of experience.
- Generate a text report.
- Handle missing file errors gracefully.

This project demonstrates how Python can be used to read structured data, process information, apply simple business logic, and generate useful reports using only the Python Standard Library.
