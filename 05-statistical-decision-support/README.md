# Project 05 – Statistical Decision Support

## Objective

Analyze sales data using descriptive statistics to support simple business decisions.

---

## Topics Covered

- Mean
- Median
- Variance
- Standard Deviation
- Maximum
- Minimum
- Mode
- Business Decision Making
