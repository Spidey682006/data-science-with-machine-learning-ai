# Project 08 – Customer Segmentation

## Objective

Group customers into different segments using the K-Means clustering algorithm based on Annual Income and Spending Score.

---

## Topics Covered

- Unsupervised Learning
- K-Means Clustering
- Customer Segmentation
- Data Analysis

## Conclusion

This project demonstrates how K-Means clustering can group customers with similar purchasing behaviour. These customer segments can help businesses create targeted marketing strategies.
