# Project 12 – Customer Segmentation Profiling

## Objective

Analyze customer clusters and create a profile for each group.

---

## Topics Covered

- Customer Segmentation
- Cluster Profiling
- Business Analytics
- Average Calculation
- Report Generation

---

## Install

```bash
pip install -r requirements.txt
```

---

## Run

```bash
python src/customer_profiling.py
```

---

## Output

```text
outputs/
├── customer_profiles.csv
└── profiling_report.txt
```

---

## Conclusion

This project summarizes customer clusters by calculating average income, average spending score, and the number of customers in each segment.
